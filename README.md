Este projeto colaborativo foi feito com foco no aprendizado de lógica de programação em Python. O jogo permite a interação entre um jogador humano e o computador, que responde com base em uma heurística simples.

⚙️ Técnicas utilizadas
Controle de fluxo: if/else, while, for, try/except

Estrutura de dados: matriz (lista de listas)

Manipulação de arquivos: registros de jogadas e resultados salvos em .txt

🧩 Funções implementadas
imprimir_tabuleiro() – Mostra o tabuleiro no console

verificar_vencedor() – Verifica se houve vencedor

tabuleiro_cheio() – Detecta empate

jogada_jogador() / jogada_computador() – Processam as jogadas

main() – Controla o fluxo geral do jogo

📁 Armazenamento em Disco
Todas as jogadas são gravadas em um arquivo .txt, configurável pelo caminho local.
